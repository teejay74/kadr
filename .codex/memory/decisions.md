# Decisions

## Доступность байтов при потоковом чтении торрента

**Component** — Streaming Manager, qBittorrent.

**Decision** — Перед чтением каждого блока HTTP Range сопоставлять смещения файла с кусками раздачи и ждать, пока qBittorrent подтвердит загрузку всех нужных кусков. Сохранять обычный приоритет выбранного файла в последовательном режиме.

**Reason** — При частичной загрузке файл на диске может содержать незаполненные области. Проверка состояния конкретных кусков предотвращает чтение таких областей.

**Alternatives** — Размер файла и общий процент загрузки не показывают готовность запрошенного диапазона. Для используемой в KADR реализации qBittorrent 5.x задокументировано, что максимальный приоритет файла может сохранять загрузку редких кусков и задерживать начало видео.

**Constraints** — Web API не позволяет назначить приоритет произвольному куску. Перемотка в ещё не загруженную область может завершиться по тайм-ауту.
