# Нативное приложение для Android TV

Нативный клиент находится в каталоге `android-tv/` и использует Compose for TV
и Media3 ExoPlayer. Это отдельный интерфейс поверх существующего API KADR;
работа с торрентами, файлами, выбором потока и правила безопасности остаются на
сервере.

## Возможности текущей версии

Версия `0.3.0` предоставляет:

- плитку KADR в системном launcher Android TV и альбомную TV-компоновку;
- управление фокусом с помощью D-pad;
- первоначальную настройку сервера с настоящей проверкой состояния KADR;
- сохранение адреса сервера в LAN, Tailscale, MagicDNS или через HTTPS;
- реальные строки популярных фильмов и сериалов;
- реальные страницы фильмов и сериалов;
- получение потока фильма через `POST /api/v1/playback/resolve`;
- поиск реальных источников через серверный Prowlarr прямо с телевизора;
- выбор раздачи с пульта по качеству, кодеку, размеру и числу раздающих;
- передачу выбранной раздачи серверному qBittorrent и ожидание готовности
  начального буфера;
- выбор сезона и эпизода сериала с пульта;
- поиск источников конкретного сезона и безопасное автоматическое
  сопоставление файлов с эпизодами через серверный Episode Matcher;
- ручной выбор файла, если сервер не смог однозначно определить эпизод;
- полноэкранное воспроизведение в Media3 ExoPlayer с HTTP Range и продолжением
  с сохранённой позиции.

Библиотека/избранное, выбор дорожек, запись истории, следующий эпизод и
совместимая подготовка будут добавляться следующими нативными инкрементами.

## Сборка APK

Используйте Android Studio с JDK 17 и Android SDK 36 либо запустите добавленный
в репозиторий Gradle Wrapper:

```bash
cd android-tv
./gradlew testDebugUnitTest assembleDebug
```

Готовый отладочный APK появится по адресу:

```text
android-tv/app/build/outputs/apk/debug/app-debug.apk
```

## Установка на телевизор

### Вариант 1: установка через ADB по сети

1. Откройте на телевизоре **Настройки → Об устройстве**.
2. Несколько раз нажмите на пункт **Сборка**, пока не включится режим
   разработчика.
3. В разделе **Для разработчиков** включите **Отладку по USB** или
   **Беспроводную отладку** — название зависит от версии Android TV.
4. Узнайте IP-адрес телевизора в настройках сети.
5. На компьютере установите Android SDK Platform Tools и выполните:

```bash
adb connect TV_IP:5555
adb install -r android-tv/app/build/outputs/apk/debug/app-debug.apk
```

При первом подключении подтвердите разрешение отладки на экране телевизора.

На новых версиях Android TV вместо порта `5555` может использоваться сопряжение
для беспроводной отладки. В этом случае телевизор покажет отдельный адрес, порт
и код. Выполните сначала:

```bash
adb pair IP_ТЕЛЕВИЗОРА:ПОРТ_СОПРЯЖЕНИЯ
```

Введите показанный код, затем подключитесь к адресу из раздела беспроводной
отладки и установите APK:

```bash
adb connect IP_ТЕЛЕВИЗОРА:ПОРТ_ОТЛАДКИ
adb install -r android-tv/app/build/outputs/apk/debug/app-debug.apk
```

### Вариант 2: установка с USB-накопителя

1. Скопируйте `app-debug.apk` на USB-накопитель.
2. Подключите накопитель к телевизору и откройте APK через файловый менеджер.
3. Если Android запросит разрешение, временно разрешите установку неизвестных
   приложений только выбранному файловому менеджеру.
4. После установки снова отключите это разрешение.

Запустите KADR из списка приложений Android TV.

## Первое подключение к серверу

После запуска приложение попросит адрес KADR. Указывайте адрес полностью, с
`http://` или `https://` и портом `8180`, если он не изменён.

Примеры:

```text
http://192.168.1.50:8180
http://100.64.0.10:8180
http://kadr-server:8180
https://kadr.example-tailnet.ts.net
```

Для подключения по LAN телевизор и сервер KADR должны находиться в одной
доверенной сети и видеть друг друга. Нажмите **Проверить и сохранить**.

Для подключения через Tailscale:

1. Установите и запустите Tailscale на сервере KADR и на Android TV.
2. Подключите оба устройства к одному tailnet.
3. В приложении KADR введите Tailscale IP сервера из диапазона `100.64.0.0/10`
   или его имя MagicDNS.
4. Нажмите **Проверить и сохранить**.

Tailscale шифрует соединение между устройствами, хотя внутри VPN приложение
обращается к HTTP-порту KADR. Незашифрованный HTTP к публичным адресам
приложение отклоняет. Для публичного имени нужен корректный HTTPS reverse proxy.
Текущий KADR однопользовательский, поэтому нельзя напрямую открывать его порт в
интернет.

## Первичная проверка

1. Плитка KADR отображается в списке приложений Android TV.
2. Стрелки пульта переводят фокус на поле адреса и кнопку подтверждения.
3. Адрес LAN или Tailscale проходит проверку состояния сервера.
4. Загружаются реальные строки фильмов и сериалов.
5. OK открывает страницу фильма, Back возвращает в каталог.
6. Если источник ещё не выбран, приложение показывает найденные раздачи.
7. Для сериала выберите сезон, серию и источник сезона. Если соответствие
   файла неоднозначно, подтвердите нужный файл на отдельном экране.
8. После выбора приложение добавляет источник, ожидает начальный буфер и
   автоматически открывает Media3 на весь экран.
9. Пультом работают пауза, продолжение, перемотка и выход Back.
10. Отдельно проверьте H.264/AAC MP4, H.264 с AC3, HEVC и MKV. Результат зависит
   от декодеров конкретного телевизора, поэтому его необходимо записать, а не
   считать поддержку гарантированной.

## Если подключение не работает

- Проверьте с другого устройства в той же сети адрес
  `http://IP_СЕРВЕРА:8180/api/v1/system/health`.
- Убедитесь, что введён IP сервера, а не телевизора, и что используется порт
  KADR, а не внутренний порт API.
- Для Tailscale сначала проверьте доступность сервера по его Tailscale IP.
- Не меняйте firewall и не открывайте порт в интернет до выяснения причины.
